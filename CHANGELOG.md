# Changelog

All notable user-visible changes to the ddns-go TOS application package.

## 6.17.1-1 — 2026-11-11

### Added
- First release. ddns-go (`jeessy/ddns-go:v6.17.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8065 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/ddnsgodocker/`.
